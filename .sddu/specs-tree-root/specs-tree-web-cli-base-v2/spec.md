## 2. 上下文
> 回顾问题背景和目标用户

### 2.1 要解决的问题（生态位视角）

作者核心认知：**传统 agent 框架依赖操作系统，web-cli-base 依赖浏览器**——浏览器环境下能力薄弱需补齐。F-23（v0.6.0）已交付框架机制层（CommandRouter 统一注册/分发、AgentRunner 中性循环、DelayGate 全局 delay、lgdl-web 单一组装点），但工具面仍只有 5 个（lgdl-web-cli / lgdl-web-op-cli / web-fetch / sleep / web-cli-help），全部绑定 LGDL 场景或平台原语（discovery §3.1）。问题域（Q-001~Q-013 收敛）为：

- **能力设计范式刚切换**：作者裁决 D-5「不照搬 OS 工具集」——read/write/edit/bash/grep/glob 是 OS/文件系统生态位语义，v2 须先做「OS 组成 → 浏览器对应组成」生态位映射（discovery §3.3 A~F 六大组），再按浏览器生态位设计工具（§3.4 九域 25+ 候选）；OS 形态的 8 项 MVP 工具不以其 OS 形态进入（D-6 派生）。
- **九域能力整体未定义**：现 5 工具只覆盖「应用文档对象 / DOM(UI) / 同源 fetch / 时序 / 元工具」五个窄生态位点；存储/检索/网络搜索/执行/任务/会话/扩展/通用 UI 自动化域零工具（Q-001/Q-002）。
- **三大 OS 生态位无浏览器宿主**：执行（shell→eval/worker/远程端点）、进程（→Worker/任务句柄）、文件（→OPFS/IDB/File System Access）需按 §3.3 承载度（○/◐/✕）映射或判不可行（Q-004）；不可承载面按代理原则处理（O-002，作者已裁）。
- **无应用级权限门禁**：router.dispatch 除 delay gate 外无钩子；AI 自动执行 UI/网络写操作零应用级护栏（Q-005，作者已裁三者组合）。
- **无状态/任务/会话/扩展体系**：会话纯内存（刷新即失）、无 todo/goal/jobs、无 skill/MCP/运行时注册（Q-006/Q-007）。
- **lgdl-web 接入面未定义**：新域工具默认开关、web-search key 来源、权限 ask UI 归属未定，防「做了没人用」（Q-011）。

### 2.4 F-23 衔接基线（已交付机制，v2 的挂载基座）

- **ToolEntry 契约**（router.ts:39-56：name/summary/schema/prefix/executor/help/delayMs/listed）——所有新域工具以注册条目形态进入即得 schema/help/dispatch/delay（「注册即得」链，F-23 FR-001~005）。
- **dispatch 同步内存查找 + delay gate**（router.ts:259-272）——无异步初始化/工具开关/权限钩子；v2 在**既有挂点同层**扩展（PreToolUse 生态位 FR-005、启用态 FR-004），不另起分发路径（FR-043）。
- **AgentRunner 事件 8 + hooks 2**（runner.ts:30-55，场景级 intercept/onToolDone）——v2 权限/ask 为**框架级**（router 层），与场景 hooks 分层（FR-005/FR-007）。
- **世界模型 = 文档态**（ToolContext {docId/source}，router.ts:71-75）——v2 扩展为「状态访问面」（会话/存储/goal 经 ctx 或注册表状态服务，FR-044）。
- **注册表两段平铺**（业务 Map + 内建 Map，router.ts:104-106）——v2 需目录/命名空间/运行时加载/开关扩展（REG 组）。
- **lgdl-web 单一组装点 session.ts**（内建自动注册 + 2 业务工具 + delayMs 600）——v2 新域工具默认注册矩阵挂载于此（LGDL 组）。
- **base 内建自动注册先例**——新浏览器原生中性工具（doc/storage/search/session 等）可直接进 base 内建或经注册注入，自动置末顺序契约（F-23 FR-005/AC-006）。
- **F-23 遗留 ⏭️**：真实 AI 闭环（AC-008）+ testConnection 需浏览器 + API Key 未闭合（validate-report.md:181-183）——v2 浏览器原生工具验证必须以真实浏览器闭环为基线（FR-045）。
