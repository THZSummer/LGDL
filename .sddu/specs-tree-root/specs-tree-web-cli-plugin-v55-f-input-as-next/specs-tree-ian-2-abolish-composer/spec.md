## 2. 上下文与边界

### 2.1 上下文

父规范 §2.2~§2.5 的**废面根因**全部落在本叶：`#composer` 是唯一「自由文本 → 发起回合」流外面（`index.html:1419-1422`）；显隐「与历史相关而非与状态相关」三缺陷（D-A 双写者 `sidepanel.ts:2884-2891` vs `l0/shell.ts:90-105`；D-B `fallbackOpen` 锁存 `:2883` 无生产复位；D-C `openL2View('settings')` `:3607-3613` 漏调 + CSS `:670-672` 不含 `#composer`）；四处兜底入口全部汇聚到 `revealAskFallback()` 但**附带** reveal 流外面（`sidepanel.ts:2893-2895 → l0/shell.ts:98-99`）；`#send-reason` 是**保留载体**（`host-registry.ts:295-321`）；`NEVER_FOLDABLE` 含 `'composer'`（`disclosure.ts:164`）；兼容读取面登记（`host-registry.ts:144-146`）；18 门禁 + 2 保护段（journey 活跃 pin `43054..58287` / sha `cc79f413…`；binding `107780..115930` / sha `be9ad0e9…`）。

**本叶的验收锚**：把「流外面」**真退役**（DOM 移除，非 `hidden`），并把**立法（法四）+ 门禁强度**同步重锚 —— **断言零删除零降级**（唯一例外 = 保护段显式取代 + 台账留痕）。
