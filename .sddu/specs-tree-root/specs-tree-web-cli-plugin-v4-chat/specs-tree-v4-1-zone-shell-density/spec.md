## 2. 上下文与边界

### 2.1 上下文

父 Feature 的核心问题 Q-CHAT-004 = **现状布局不是三区，过程没有承载面**；Q-CHAT-008 = **可点预算全被一次性交互占满，准入规则缺失**；Q-CHAT-005（部分）= 系统事件散落两区 6+ 通道；Q-CHAT-013（部分）= 管理操作在 F 三区法则下无归属。本叶负责先把「房子」立起来：三区骨架 + 预算准入规则 + 风险 chips 新形态 + 密度重定标，为 v4-2/3/4 提供承载容器与共同基线。

### 2.2 范围（做 / 不做）

**做（in）**：

- 三区骨架：`header#region-toolbar[role=toolbar]` → `main#region-stream`（含 `ol#stream[role=log]` 容器）→ `footer#region-statusbar[role=contentinfo]`；顺序与语义（父 FR-CHAT-010）。
- 工具栏准入：站点摘要（只读 `role=status`，不计入预算）+ 4 视图入口（树/命令/审计/设置，带计数徽标，复用 `l2/counts.ts` 单源）+ 主题切换 = **可点 ≤5**；准入与置换规则登记（父 FR-CHAT-011 / FR-CHAT-016 管理操作入视图）。
- 工具栏/状态栏**禁止一次性交互**（法一可静态核验，父 FR-CHAT-012）。
- 状态栏常驻：连接状态一行 + 风险 chips（有则显示、无则收缩一行 0 chip）；本体无 `hidden`、chips 容器可见（父 FR-CHAT-013）。
- 法四：默认屏无可见常驻输入框（父 FR-CHAT-014）。
- L2 视图替换机制复用：打开视图层可见 + 流隐藏 + 标题正确；返回恢复（父 FR-CHAT-015）。
- 风险位形态迁移为状态栏 chips；**永不折叠语义保留** + 新机器判据（父 FR-CHAT-004 / FR-CHAT-017）。
- **密度新口径**：测量根 = 三区外壳；流内容不计入默认密度；豁免边界只认 `hidden`；单卡可点 ≤6；首屏卡片 ≤2；阈值 7/15 · 9/20 · 17/35 保留；v4 新基线文件 + 登记格（9 强制格 + 15 风险格 + worst + 阶段 F 比对格）重算；**逐条反证**（父 FR-CHAT-070~075）。
- 双主题 + 320–560px 零水平溢出（本叶相关 NFR）。

**不做（out）**：

- 不做流内 7 主类 / 过程卡族的渲染与事件模型（父 STREAM/CARD 组）→ 归 v4-2。
- 不做 ask-user / 授权卡流内化与固化（父 FLOW 组）→ 归 v4-3。
- 不做引用卡 / 系统事件行 / 推荐卡内容（父 TRACE/NEXT 组）→ 归 v4-4（本叶只提供状态栏 chip 容器与骨架）。
- 不做 V3-VOL-3 体积基线重定与绝对上限闭合（父 VOL 组）→ 父级收口锚，由最后完成叶执行；本叶只做**中间重登记**（五要素）。
- 不新增静态权限、不引入 `contextMenus`、不改判定链（`policy.ts`/`auto-authorize.ts`）、不碰 `src/content/**`。
- 不删除或降级任何既有断言；不以放宽密度/体积上限换功能。

### 2.3 与父规范的关系

- 权威条文：父 §5.2（ZONE）+ §5.8（DENSITY）+ §9（密度新口径）+ §10（取代台账）+ §8.1~8.2 / §8.4（AC）。
- 本叶是本 Feature 的**首个开工叶**：其产出的三区骨架与密度新口径是 v4-2/3/4 的**共同基线**。
- 本叶遵循父 §12 裁决记录：O-CHAT-003（工具栏准入）、O-CHAT-004（绝对上限推导规则，本叶只做中间重登记）、O-CHAT-005（法则六，管理入视图）、O-CHAT-007（风险位新判据）、R-CHAT-004（密度口径）。
