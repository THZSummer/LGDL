## 2. 上下文与边界

### 2.1 上下文

- **R3 / C1 / C6**：`requestTurn` 是面板**唯一**回合发起入口，调用点被 `test/op-wiring.test.ts#requestTurnProblems` 钉死**恰 2 处**（`sidepanel.ts:3232` composer / `:3256` `bindPanelOps.turn`）。AI 的驱动权**止于回合内**（`service-worker.ts:908-926` 的 thinking / command / tool 指示器），**不能启动回合**。⇒ 作者主题②「让 AI 来启动整个 chat/next」在架构上**不可达**（不是缺一个 chip）。
- **C5**：`chatBusy` 单飞（`service-worker.ts:879-885`）——并发第二条**被丢弃**并回错误（逐字「上一条消息仍在处理中，请稍候再发送。」）⇒ AI 主动与用户手输撞车时**用户输入可能被静默丢弃**。
- **C1 / C2**：**特权 op 恰 2**（`op.authorize` / `op.perm.request`，`ops.ts:24` 逐字「the pipeline never calls their `execute` …routes them through `bindSwExecutor`」；`IMPL` 行内二者 `execute = null`），且「**SW 永不调用 `.request(`**」（`test/capability-wiring.test.ts:51-58`）⇒ **特权 op 必须用户手势**是**不可让渡**红线。**但「AI 可主动发起哪些 op」的清单当前不存在**（Q-SELF-010）。
- **C8 / D7 / D1 / D3**：注册表服务面 `NEXT_SERVICES` 6 / `NEXT_MODES` 2 / `NEXT_MOUNT_POINTS` 5；12 kind（7 + 5）；零宿主（`REGISTERED_STRUCTURAL_HOSTS = []`）；防抖三常量（10 s / 单卡 ≤3 chip / 每回合 ≤1 卡）。
- ⇒ 「主动性」一旦成立，会引入**三个全新的成本 / 稳定性面**：**token 消耗**、**主动跨轮**、**自触发环**（Q-SELF-013）；而**三条控制当前零判据**。

### 2.2 范围（做 / 不做）

**做（in）**：

- **AI / 系统启动回合**：经**既有 `op.turn` 槽**（= 既有唯一回合入口 `requestTurn` 的既有接线）；`requestTurn(` 调用点**保持恰 2 处（diff = 0）**；新增的只是「谁触发 `op.turn`」的**驱动者**（`driverClass: 'ai-driven'`）。
- **op 三档清分**（**单源 + 机核**）：`auto`（5：`op.pick` / `op.describe` / `op.help` / `op.rebind` / `op.turn`）/ `confirm`（2：`op.llm-config` / `op.revoke`）/ `gesture`（2：`op.authorize` / `op.perm.request`，**恒在此档**）；**新 op 必须归档**（未归档 ⇒ FAIL）；**AI 不得降档**；清分与既有 `IMPL` 的 `riskLevel` / `consent` / `layer` 声明**一致**（不一致即红）。
- **护栏三件套**（**单源常量 + 越限被抑制 + 机核**）：① 打扰控制（频次上限 / 同因不重复 / 静默期；继承既有 10 s 防抖**不改常量**）② token 成本（AI 主动回合**预算上限**，达界停发且非死端）③ 防环（连续自动链**深度上限** + 冷却，达界强制转用户手势）。
- **并发仲裁**（`chatBusy` 语义重锚）：AI 主动 + 用户手输撞车 ⇒ **可判仲裁**（排队 / 合并 / 明确拒绝并保留用户输入；具体策略由 plan 定，但**用户输入永不静默丢失 + 留痕可判 + 有界**）。
- **AI 主动留痕三要素**（driverId / ts / 依据摘要；**零明文**）+ **候选恒由注册表产出**（AI **不得**自造 opId）+ 失败非死端 + **不触碰判定链**。
- **用户否决权 + 总开关**（关断后 AI 主动零发起；**主题① 不受该开关控制**——口径显式登记）。
- **零新增载体**：12 kind / `REGISTERED_STRUCTURAL_HOSTS = []` / `KIND_SET` 40 项逐字。
- **三叶共享面收口**：体积五要素（含越限路径登记）/ journey+binding 保护段（优先保段，否则八步取代）/ 取代台账（`modifiedRanges[]` / `redlineRemap[]`）/ `knownGap` 一致性 — **各恰一次登记**。

**不做（out）**：

- **不做主题① 的引导内容 / `runChat` 前置判据**（那是 `v55-2`）——本叶只**消费**配置判据（分流依据）。
- **不做驱动者层底座 / 时机源 / 终态词汇**（那是 `v55-1`）——本叶只**消费**（候选来自注册表 + `'answered'` 时机）。
- **不改判定链**（`src/security/policy.ts` / `auto-authorize.ts`，`zeroDiffFiles` 9 项**零触碰**）；**不改特权 op 的手势语义**（只**加固**：清分 + 机核）。
- **不新增静态权限**（**连 `optional_permissions` 也不新增**）；不改 `manifest.json`；不改 `KIND_SET`；不新增卡类型 / 流内固定宿主。
- **不碰 `src/content/**` / `dist/content.js` / `dist/pick-layer.js`**；不改 ROADMAP；不碰 `design/**`；不改写 v5 产物；**不删除任何 v5 已建门禁**。
- **不把「主动」实现为散落调用点**（第二份半驱动者）或**新增 `requestTurn` 调用点**（读法①）。
- **不做外部竞品调研**（O-SELF-007 已裁决「不需要」）。
