## 2. 上下文与边界

### 2.1 上下文

父规范 §2.2~§2.3 的**回归风险面 + 判据治理面**全部落在本叶：确定性注册表的**兜底位置未定**（`Q-ADN-006`：R8 刚修好「首开零 next 死端」，若 AI 化让确定性产卡路径失守 ⇒ 静默回归）；**free-input 终端恒常驻不回归**（`Q-ADN-007`）；**AI 候选与规则候选的合并 / 优先级 / 去重 / 上限缺位**（`Q-ADN-008`：单卡 `MAX_NEXTSTEP_CARDS_PER_ROUND=1` + `NEXTSTEP_PRIORITY` 恰 4 + `MAX_CHIPS_PER_CARD=3` 装不下「AI 一次 4 条」）；**护栏 / 预算口径未定**（`Q-ADN-009`：六常量今天只服务「AI 主动回合」，提案 vs 回合成本须分列）；**首开 AI 化边界**（`Q-ADN-010`）；**门禁只增不减 vs 产出面转移的张力**（`Q-ADN-014`：`recommendation-sources` / `driver-timings` / `driver-quadruple` / `op-wiring` 逐条重锚）；**体积压力**（`Q-ADN-013`：距档仅 15,474 B）。

**本叶的验收锚**：在叶1 已建通道与校验链之上，**保证「AI 化不回归（兜底 / 终端 / 首开）」+「多候选不溢出」+「门禁强度不降」**。
