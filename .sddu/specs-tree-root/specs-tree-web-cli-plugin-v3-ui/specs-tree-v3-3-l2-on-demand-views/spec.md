## 2. 上下文与边界

### 2.1 上下文

v2 已把**四维连接树 / 122 卡命令档案 / 撤销回执**压进同一屏，v1 已有**审计**与**设置**；作者反馈的本质是这些「底账」与「当前要做的一件事」被放在了同一平面上（Q-UI-002），且每加一个能力默认首屏就更挤（Q-UI-004）。E 稿的解法 = **L2 按需视图**：默认一个都不出现，只在状态栏留「计数 + 入口」，≤2 次交互可达，打开后是**同一内容区的视图替换**（不是浮层、不是第二个滚动容器），顶部有「← 返回」。

本叶子的主要工作 = **改归属方式 + 补摘要/计数/入口**，**复用既有资产**（`tree-drawer` / 命令档案 / 审计 / 设置实现），并承担 **R-UI-002 取代台账的最大工作量**（既有 insight 108 / binding 192 断言大量落在树 / 回执 / 确认上）。

### 2.2 范围（做 / 不做）

**做（In Scope）**：

1. **L2 四类视图**：全局连接树（四维度）· 命令目录（122 卡 + L1/L2/L3 归档）· 审计 · 设置；**默认一个都不出现**（全部在 `hidden` 子树内）。
2. **「计数 + 入口」形态**：入口只存在于 L0 状态栏入口面板；**计数从真值派生**（改真值计数随之变化，硬编码即 FAIL）。
3. **视图替换 + 返回**：同一内容区替换（单滚动容器，不引入第二个滚动容器）、顶部「← 返回」、返回后回到进入前的 L0 展开状态。
4. **可达性**：L2 ≤2 次交互；L2 打开期间**风险位仍常驻可见**（不得被视图替换掉）。
5. **命令目录口径**：逐条呈现每命令处置档（`allow` / `ask` / `deny`）+ 来源 + 生效值；硬底线不可覆盖档**零控件** + 原因可读；`delay` 与 `deny` 同处并标（delay = deny，fail-closed，非可配置档位；与命令间 `delayMs` 无关）；实时面与对账基线口径**分列**（不复用设计稿数字当验收值；如实登记差异）。
6. **审计视图**：条目列表 + 零明文纪律（通知 / 剪贴板 / 书签内容零明文，只记长度 / 路径 / basename；URL 默认去参）。
7. **设置视图**：复用 v1 设置面板既有实现与项语义（不删项、不改语义、不改 `options.html`），只改默认可见性。
8. **全局连接树**：复用 v2 真层级树（`role=tree/treeitem` + `aria-expanded`/`aria-level` + 键盘 + 面包屑）；保留 9 个树内动作白名单（固定序）与只读投影性质。
9. **L2 关闭后密度复位**：返回后 L0 密度回到默认档（不残留额外常驻元素）。
10. **能力集等价**：全展开态下四类底账与改造前逐项等价（数量与内容不减）。

**不做（Out of Scope）**：

- 不做 L0 常驻骨架本体与密度门禁（归 **V3-1**；本叶复用并保持其基线）。
- 不做 L1 展开内容（后果说明 / 引用证据 / 局部树 / 回执证据 / 手势表）→ 归 **V3-2**；本叶只提供「审计出口」等**被指向**的视图。
- 不做页面侧交互 → 归 **V3-4**。
- **不新增任何判定路径 / 权限 / 放宽控件**；不改安全判定链；不推翻 v2 的覆盖层与 SW 侧 clamp；不删改 v1 设置项语义与 `options.html`。
- **不删除、不降级既有断言**（本叶取代量最大，但纪律不变）。

### 2.3 与父规范的关系

- **权威条文在父 spec**（§5.4 / §8.3 / §8.4 / §10）；本文件只做范围 / 依赖 / 验收锚点 / 独立性切片。
- **编号**：沿用父的 `FR-V3-*` / `AC-V3-*`，不新增命名空间。

## 10. 边界登记（收口轮追加，validate R1 N-08 —— 只追加，不改上文任何条文）

> 以下为**实现边界的事实登记**：validate R1 实测确认「设置视图」不在 `#view-host` 视图替换契约内，属**已实现但未在 spec/plan 显式登记**的边界。按 N-08 的处置要求就地补登一句；**上文 FR-V3-047 / FR-V3-051 的措辞与编号逐字保留**，本节不与上文冲突，只界定判据的适用范围。

**`FR-V3-047` 的「单滚动容器」判据适用范围 = `#view-host` 三视图（树 / 命令目录 / 审计）**：设置视图由 v1 既有开关承载（`body.settings-open` + `#panel-main` 计算态 `display:none`），其滚动容器 `#settings-view` 位于 `#panel-main` 之外，关闭由 `#settings-back` 返回 —— 因此「同一内容区替换 / 面板级恰一个滚动容器 / 顶部「← 返回」」这三条判据**对设置视图不适用**，对它是另一套等价实现（CSS 层开关 + 自身返回按钮），与 `FR-V3-051`（复用 v1 设置面板既有实现，只改默认可见性）一致。

**判据登记位置**：`test/ui/l2.mjs` ⑩ 显式断言设置视图「仍由 v1 返回按钮关闭」；密度登记册 `knownLimitations` 另登记「面板打开态无密度登记格」（N-07）。
