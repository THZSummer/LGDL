## 2. 上下文与边界

### 2.1 上下文

父问题的第三面：**五类高后果信息与普通信息同密度并列、无永不折叠常驻位**（Q-UI-003）。E 稿的处理方式是「**就地展开**」：与当前任务强相关的内容点开即见、用完收起（≤1 次交互），而不是塞进覆盖式抽屉。本叶子把「就地展开」实现为可验证契约，并承载 **O-UI-002 的裁决**（引用失效判定必须 fail-closed）——discovery 已提示：若本叶承载其呈现，判定语义必须先在 spec 定死（现已定于父 §5.3 FR-V3-036~038）。

### 2.2 范围（做 / 不做）

**做（In Scope）**：

1. **L1 就地展开（8 类内容，逐类 ≤1 次交互）**：① 状态与连接详情 ② 选项的后果说明与影响预演 ③ 引用 chip 证据 ④ 局部树（当前对象所在 2~3 节点）⑤ 已决策历史（含改选）⑥ 回执三件套的完整证据 ⑦ 页面交互说明（手势表）⑧ 「更多选项」里的其余选项。
2. **就地展开约束**：展开**不遮挡** L0 决策卡与风险位；展开入口必须带文字标签 + 摘要/计数；同一位置规则一致（同一套折叠器语言）。
3. **后果说明与影响预演**：每个选项「会发生什么」+「不会发生什么」两段；破坏性选项额外**不可逆性声明**。
4. **引用 chip 证据**：稳定选择器 + 语义路径 + 文本摘要（截断）+ 捕获时间；证据层只读。
5. **引用失效判定（fail-closed，父 FR-V3-036）**：五维任一成立即失效（DOM 消失 / origin 变更 / 页面导航含 SPA / 站点声明版本变化 / 授权被撤销）；**不确定即失效**。
6. **引用失效呈现与恢复**：失效进入 **L0 风险位（永不折叠）** + 可读原因（哪一维触发）+ chip 标记失效 + **阻断**用失效引用发起动作 + 「重新拾取」（≤1 次交互）与「改用描述」（走末项兜底输入）两条恢复路径。
7. **回执三件套**：摘要常驻 L0（或状态栏摘要位），完整证据与审计出口在 L1（≤1 次交互）。
8. **局部树**：只呈现当前对象所在 2~3 节点 + 归属链 + 「查看全局树」入口（指向 L2，2 次交互可达）。

**不做（Out of Scope）**：

- 不做 L0 常驻骨架与密度门禁本体（归 **V3-1**；本叶**复用**其折叠器 / 摘要契约 / 展开态记忆，并必须保持 V3-1 的密度不回归）。
- 不做 L2 四类视图内容（全局树 / 命令目录 / 审计 / 设置）→ 归 **V3-3**；本叶只提供「查看全局树 / 审计出口」等**入口**。
- 不做页面侧交互实现（Alt 悬停 / Alt 拖动 / 右键自绘 / 拖选气泡 / 双向联动 / 角标）→ 归 **V3-4**；本叶的引用对象可用**注入的引用态**验证（含 5 维失效注入），但**页面侧真实捕获**由 V3-4 承接。
- 不新增权限 / 依赖 / 判定路径；不改安全判定链与 `content.js`；不删既有断言。

## 4. 功能需求（本叶承载的父 FR）

| 父 FR | 关注点 / 本叶补充 |

| **FR-V3-035** | 「已决策 N 步」的 N 可复算；展开列出已决策回合（含改选）；**回看不改变已执行动作**（零副作用） |
| **FR-V3-036** | 5 维判定逐一可注入验证；**不确定即失效**（含选择器歧义、元素被替换为同类新元素）；判定必须发生在侧栏侧（不要求页面侧在场） |
| **FR-V3-037** | 失效进**风险位（L0 常驻、永不折叠）**；可读原因必须指出**哪一维**触发；**阻断**动作（禁用或改写为「重新拾取」）；不得静默沿用、不得静默丢弃（丢弃也是一种静默） |
| **FR-V3-038** | 「重新拾取」≤1 次交互；「改用描述」走到末项兜底输入（复用 FR-V3-012）；恢复后引用回到有效态 |
| **FR-V3-039** | 三件套逐件可达：摘要（L0 常驻）+ 证据（L1）+ 审计出口（L1 或指向 L2 审计视图）；三件套缺一即 FAIL |
| **FR-V3-040** | L1 入口遍历断言：文字标签非空 + 摘要或计数非空 |

## 6. 边界情况（本叶相关）

| 父 EC | 本叶落点 |
|-------|---------|
| **EC-V3-001** | **引用失效 fail-closed**：五维 + 不确定 → 失效；可读原因；阻断动作；两条恢复路径（本叶为**主要**落点） |
| **EC-V3-006** | 元素在操作过程中消失：撤销高亮、标记失效、不发命令；若已进入确认阶段则回到「未执行」并在回执如实登记 |
| **EC-V3-007** | 扩展重载 / SW 休眠：恢复后重新解析引用有效性；无法确认按失效处理；不得回放失效引用 |
| **EC-V3-014** | 多标签 / origin 切换：A 站点引用不得带到 B 站点（origin 变更即失效） |
| **EC-V3-015** | 破坏性确认期间折叠全部披露层：风险行与确认选项仍在 L0 可见 |

## 8. 独立性说明（**能独立做到全门禁绿**）

| 维度 | 说明 |
|------|------|
| 改动面 | 仅侧栏侧（L1 展开内容与引用态模型 + 必要的视图模型扩展）；**不碰**页面侧 `src/content/**`、不碰权限、不碰判定链 |

| 既有断言取代量 | 中等：回执三件套 / 确认 / 树相关断言集中在 insight / binding；须逐条 old → new 台账登记（`count ≥ 108` / `≥ 192`） |
| 可独立验证 | 5 维失效判定、可读原因、阻断动作、两条恢复路径、8 类 L1 可达性、回执三件套——**均可在侧栏侧构造与验证**（引用态注入）；不依赖 V3-3 / V3-4 产物 |
| 门槛 | `tsc` 0 error + 插件单测全绿 + `test:ui` ≥167 + `test:insight` ≥108 + `test:binding` ≥192 + `test:hardening` 24 + `test:e2e` PASS + 密度门禁不回归 + 反证实跑（**串行**、日志完整落盘） |
