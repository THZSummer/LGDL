## 2. 交付了什么（面向使用者的三句话）

1. **默认首屏从「全部能力平铺」变为「随用随取」的三层披露**（L0 常驻 / L1 就地展开 / L2 按需视图）：默认档 **≤7 可点元素 / ≤15 可见正文行**（实测 **7 可点 / 7 行**，320·400·520 三视口逐项相等），密度由四项机器可复算口径 + 三档阈值（≤7/15 · ≤9/20 · ≤17/35）+ 反作弊规则（**只有 `hidden` 属性豁免计数，CSS 隐身仍计入**）承载，且门禁**能真 FAIL**（RP-V3-01~09）。
2. **不再有输入框——「页面即输入」**：Alt 悬停拾取 / Alt 拖动入侧栏 / 右键自绘菜单（零新增权限 + 三退让）/ 拖选文本气泡 → 生成引用 + 选择题（末项固定「其他…（我来描述）」）；拾取层**按需注入**（独立 bundle `pick-layer.js`），未授权站点**零注入**，chip ↔ 页面角标双向高亮同序号。
3. **风险与状态永不折叠**：5 类风险状态（未授权 / 探测中 / 硬底线被拦 / 破坏性待确认 / 引用失效）各自独立常驻成区，DOM 祖先链断言 + 破坏性确认选项不参与折叠；收起必有「计数 + 入口」（**禁止无线索隐藏**）。
