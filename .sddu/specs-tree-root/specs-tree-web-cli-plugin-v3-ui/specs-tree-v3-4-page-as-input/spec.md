## 2. 上下文与边界

### 2.1 上下文

现状意图表达**通道单一**：唯一入口是 `#composer` 打字（Q-UI-005），页面侧**零交互零可发现性**（Q-UI-006；`manifest.json` **无 `contextMenus`**，连平台级右键菜单都不存在）。D4③ 要求「页面即输入」：Alt 悬停拾取 / Alt 拖动入侧栏 / 右键自绘菜单 / 拖选文本气泡 → 生成引用 + 选择题。

**本叶是唯一触碰 `content.js` 的叶子**，且 `dist/content.js` 实测 **177,076 B = `CONTENT_MAX_BYTES`（余量 0 字节、无容差）**；同时必须维持既有**登记式零注入**哲学（未授权站点零注入）。因此 O-UI-003 裁决被固化为需求约束：**首选按需注入**（拾取层不打进常驻 `content.js`）；**若不可行**才允许显式**重登记**体积基线（前后值 + 日期 + 来源 + 理由 + 历史保留）；**禁止以放宽上限换功能**。

### 2.2 范围（做 / 不做）

**做（In Scope）**：

1. **四项交互**：① Alt 悬停拾取（描边 + 语义路径 / 选择器 / 文本摘要）② Alt 拖动到侧栏（跟随胶囊 + 落点高亮）③ 右键**自绘**菜单 ④ 拖选文本气泡 → 生成引用 + 选择题。
2. **拾取即选择题**：拾取结果 = 1 个引用 chip + 1 道选择题（**不是**自由输入框）；自由文本只出现在末项「其他…（我来描述）」。
3. **交互副作用约束**：Alt 悬停**唯一高亮**、`Esc` / 释放 Alt 即撤销、**拾取期间零命令发送**；Alt 拖动落点两路径（落侧栏 / 未落）；右键自绘菜单**三退让**（仅已授权站点生效 / 保留「交给页面原生菜单」出口 / `Esc` 与点击空白即关）。
4. **双向高亮联动**：侧栏 chip ↔ 页面角标**同序号**；hover 任一侧高亮另一侧；引用 id 贯穿「页面角标 / 侧栏 chip / 证据层 / 失效风险行」四处。
5. **注入模型**：页面侧**按需注入**（拾取层不打进常驻 `content.js`）；**未授权站点零注入**（不注册监听、不渲染拾取 UI、不拦截右键）；页面侧 UI 只在已授权站点存在。
6. **零新增权限**：不引入 `contextMenus`、不扩大 `host_permissions`、不新增静态权限。
7. **宿主页面兼容**：自绘 UI 在宿主样式污染下仍可读；**不破坏宿主交互**（不吞宿主非目标键盘 / 点击事件）。
8. **手势清单一致性**：L1「页面交互说明（手势表）」列出的手势数 = 实际实现并验证的手势数（不得多列未实现项）。

**不做（Out of Scope）**：

- 不做 L0 骨架 / L1 内容 / L2 视图（归 V3-1 / V3-2 / V3-3）；本叶只**消费**其契约（选择题、引用 chip、折叠器）。
- 不做引用失效判定逻辑本体（归 **V3-2**，父 FR-V3-036~038）；本叶负责**页面侧产生失效事件**（元素消失 / 导航 / 声明变化）并按契约上报。
- **不**新增静态权限、**不**引入 `contextMenus`、**不**扩大 `host_permissions`、**不**改为静态注入。
- **不**为落地功能放宽 `CONTENT_MAX_BYTES`（无容差）或静默更新 `CONTENT_SOURCE_SHA256`；**不**删除既有 `src/content/**` 能力。
- **不**删除 / 降级既有断言（binding 192 中页面侧断言须走取代台账）。

### 2.3 与父规范的关系

- **权威条文在父 spec**（§5.5 / §8.4 / §6 NFR-V3-003~007）；本文件只做范围 / 依赖 / 验收锚点 / 独立性切片。
- **编号**：沿用父的 `FR-V3-*` / `AC-V3-*`，不新增命名空间。

## 8. 独立性说明（**能独立做到全门禁绿**）

| 维度 | 说明 |
|------|------|
| 改动面 | **唯一**触碰 `src/content/**`（+ 可能的按需注入登记机制）与侧栏侧引用 chip / 角标联动的叶子；不碰权限、不碰判定链、不改 `options.html` |
| 风险集中度 | **R-UI-001（`content.js` 余量 0）+ R-UI-004（`contextMenus` 缺失）+ R-UI-008（零注入红线）三条风险全部集中** → 必须**最后开工**，且需**前置 spike 通过**（A-UI-004）再动 |
| 依赖处理 | 消费 V3-1（选择题 / 引用 chip / 折叠器）与 V3-2（引用证据 / 失效呈现）的**行为契约**；页面侧与侧栏侧解耦，故依赖面窄 |
| 可独立验证 | 四项交互、三退让、零注入、体积守卫、同序号联动、零命令发送——均可用 E2E / binding 类门禁在**已授权 fixture 站点**上独立断言（未授权场景单独断言零注入） |
| 红线（本叶特有） | ① 体积：**不得**放宽 `CONTENT_MAX_BYTES`（无容差）；② 权限：**不得**引入 `contextMenus`；③ 注入：**不得**改成静态注入；④ 失效：**不得**静默沿用引用 |
| 门槛 | `tsc` 0 error + 插件单测全绿 + `test:ui` ≥167 + `test:insight` ≥108 + `test:binding` ≥192 + `test:hardening` 24 + `test:e2e` PASS + 体积门禁（含 +1B 反证）+ 零注入门禁 + 密度不回归（**串行**、日志完整落盘） |
