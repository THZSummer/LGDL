## 2. 上下文

### 2.1 要解决的问题（11 项缺口 + 载体分层 + push 缺失）

作者立项背景沿用 v2/v3 公理：**web-cli-base = AI 帮人类操作浏览器**——
- **A1 场景完备性**：人类日常操作浏览器的完整场景理论上都应有对应工具给 AI。
- **A2 F12/爬虫等效性**：凡人类靠 F12 开发者工具或爬虫才能做的，web-cli-base 也应提供等价工具。

v2（46 FR 九域）+ v3（45 FR：DOM 27 子命令 + wait/page-eval/extract/export/chrome + 子命令级权限）已完成「页内拉式工具集」的铺面与纵深，但 v4 discovery 对 11 项缺口整体排查后确认三条结构性缺环（discovery §1.3/§6.1）：

- **P1 推送面缺失（Q-001）**：当前架构 = request→response，无 push/订阅通道（router/tools grep emit/subscribe = 0 命中）；事件监听/观察流（DOM 事件、页面生命周期、console/网络观察）这类「持续发生、需主动推给 AI」的能力整体无法表达。AI 等用户完成操作/等导航/等网络失败只能 sleep+快照轮询猜时序——「事件驱动」类场景（表单补全继续、登录后继续、SPA 跳转跟随、console 报错感知）不可委派。
- **P2 载体分界未定义（Q-002/Q-008）**：11 项中 6 项是「页内可达 + 需浏览器扩展」分层体（C-01/C-03/C-04/C-06/C-08/C-09）、2 项纯需扩展（C-02/C-10）、1 项纯页内（C-07）、2 项待定（C-05/C-11）。v3 对不可承载项以单值 out 记录并挂账「F-14 扩展宿主」（NG-003/NG-004/NG-009/FR-028 整页截图），但扩展载体（浏览器扩展工程）本身未定义。
- **缺环分布**：网络层观察（Q-003）、对话框处理（Q-004）、文件上传（Q-005）、cookie/凭据与授权面（Q-006）、剪贴板仅文本（Q-007）、shadow/iframe 定位断层（Q-010）、跨导航续接（Q-011）、新载体安全门禁未配套（Q-012）等——其中**页内可达切面**多为「快赢」：机制上当前架构即可表达（§4 分层表 🟢 列），但 v3 以「不可承载/未触及」整体跳过或判死，未做切面级分界。

**业务影响**：AI 操作浏览器的边界被锁死在「单页拉取」——事件驱动场景靠猜、外壳级能力不可达、凭据/授权面零覆盖；「分层体」的能力（网络观察/对话框/cookie/剪贴板/定位）页内可表达的一半与需扩展的一半被一锅处理，缺一个「页内快赢先行 + 扩展线契约预留」的切面级分界。

### 2.4 与 v2/v3 的衔接基线（v4 挂载面，代码事实）

- **v2/v3 已交付（additive 承载面）**：dom 工具 **27 子命令**（dom-tools.ts:58-97：v2 既有 7 = read-state/click/hover/scroll/zoom/fullscreen/snapshot + v3 20 = interactives/read-element/find/structure/dblclick/contextmenu/long-press/drag/focus/blur/type/press/set-text/set-attr/remove-attr/set-style/set-value/fill/add/remove）；v3 新工具 wait/page-eval/extract/export + chrome（print/back/forward/reload/screenshot，chrome-tools.ts:38-41）；**subcommandRisks 子命令级风险**（permission.ts:34 ToolRisk='read'|'write'|'external'|'ui'|'state'|'evaluate'，evaluate=最高档 default deny，permission.ts:167-171）；敏感字段脱敏（v3 FR-024）；PlatformEnv/PlatformDomOps 全缝可选 + 自由扩展位 `[k:string]:unknown`（platform.ts:128-162/435-451）。
- **v2/v3 遗留移交（v4 前置/并行基线）**：①v2/v3 均在 `feature/web-cli-base-v2` 分支 **v0.7 位未合入发布**——v4 开发基线 = 同分支代码位（R-03）；v2 收口人工清单（真实 AI 闭环 AC-008 等）+ v3 浏览器冒烟收口面为 v4 验收的**前置或并行人工基线**（FR-004）；②事件观察/override/instrumentation 均为 v3 未触及面（grep emit/subscribe/cookie = 0 命中，discovery §3.1）→ v4 新增能力与既有 request→response 工具面互不重叠。
- **v4 挂载纪律（v2 FR-043/v3 FR-001 契约延续）**：全部新增以 ToolEntry 追加（新工具/新子命令/PlatformDomOps 或 PlatformEnv 新缝可选方法/enabled 等，缺省兼容）接入既有 CommandRouter，**不重写九域架构**；F-23/v2/v3 顺序契约（注册序 + 内建置末）、delay gate、PermissionGate 裁决管线全部保持；dom 既有 27 子命令 + v3 全部工具行为**零回归**（FR-001）。
- **push 通道与既有工具面的关系（硬约束）**：push 通道为 **additive 新增机制**——不影响既有 request→response 工具面（所有既有工具保持一问一答形态）；事件流以「订阅 → 缓冲 → 拉取/摘要」新契约接入（FR-008/013），不在任何既有工具内嵌推式副作用（FR-001 验收含此断言）。
- **开发基线**：`feature/web-cli-base-v2` 分支代码位（R-03，与 v3 同）；v2/v3 合入 main 时若重构/冲突按 additive 最小冲突原则处理。

### 2.5 场景→能力面口径（本规范问题域边界）

以 discovery §3.3 11 项逐项排查 + §4.1 载体分层总表为问题域基座，按**切面（aspect）**而非能力划分：

| 候选能力 | 页内可达切面（🟢，v4 落地） | 需扩展切面（🔴，v4 只做分界+契约预留，EXT 组） |
|---------|---------------------------|-------------------------------------------|
| C-01 事件观察流 | **事件订阅/缓冲/push 通道（必做 R-02）+ DOM 事件流 + 生命周期 + console 观察** | 跨导航持久续接、浏览器级导航完成事件 |
| C-02 多标签/窗口 | —（window.open 子集价值低且破坏会话上下文，不做） | chrome.tabs/windows：枚举/激活/新建/关闭 |
| C-03 对话框 | **页面 JS 模态框 override（alert/confirm/prompt 捕获 + 策略应答）** | 浏览器原生对话框（HTTP auth/权限 prompt/原生确认） |
| C-04 网络层 | **宿主页自身 fetch/XHR 观察（URL/状态/耗时/响应头子集）** + **发出前修改拦截（P2 门禁）** | 非 JS 子资源/跨 realm/先网络栈拦截、响应伪造（webRequest/DNR/CDP） |
| C-05 文件上传 | —（NG-004 保持 out，O-006：DataTransfer 内存注入面亦不实现） | CDP DOM.setFileInputFiles 真路径注入 |
| C-06 cookie | **同源非 HttpOnly 读（值脱敏）+ 写/删除（门禁）** | HttpOnly/跨域/域级批量管理（chrome.cookies） |
| C-07 富剪贴板 | **富内容写（text/html/image）+ paste 事件读** | 无手势系统剪贴板读/历史 |
| C-08 touch | **合成 touch 派发（P2 验证门）** | CDP Input.dispatchTouchEvent 真受信触控 |
| C-09 shadow/iframe | **open shadow 递归 + 同源 iframe 文档内定位增强** | closed shadow、跨域 iframe（content script all_frames/CDP） |
| C-10 下载管理 | —（v3 save/download 触发链保持；不做真下载管理） | chrome.downloads：枚举/进度/取消/历史 |
| C-11 权限模拟 | —（页内 patch = 欺骗注入，风险/价值比不佳，out） | CDP Browser.setPermission / 启动 flag |

## 5. 功能需求 (FR)

> 每个需求必须有唯一标识符且可测试。按十一组组织：**BSL**（v2/v3 衔接基线）/ **PRM**（安全模型升级，O-008）/ **EVT**（事件 push/缓冲/订阅通道，R-02 必做）/ **DIA**（对话框处理）/ **NET**（网络拦截）/ **CK**（cookie）/ **CLP**（剪贴板富内容）/ **SHD**（shadow/iframe 定位）/ **TCH**（touch 合成）/ **EXT**（扩展线分界与契约预留）/ **LGDL**（lgdl-web 场景接入）。
> 编号约定：FR/NFR/EC/AC 为 v4 内编号；引用 v2/v3 需求一律标「v2 FR-xxx」/「v3 FR-xxx」；引用 discovery 一律标「Q-xxx/O-xxx/C-xx」。
> 建议态标注 = 作者授权本规范的缺省决策（§9.3 S-01~S-10），plan/作者确认后冻结；未标注 = 基于已裁红线（R-01~R-03）可直接测试。
> **能力面硬约束（跨组）**：全部新能力 additive（FR-001）；事件观察流只读宿主自身同源 realm（NG-002/010）；「需要浏览器扩展才可表达」的入参/子面一律返回「不支持 + 归属说明」（FR-025），不静默降级、不假装生效。

|----|---------|---------|--------|
| FR-008 | **事件订阅机制（通道核心）**：新增**订阅机制**——注册订阅（返回唯一 subscription id）/列出现有订阅（含 id/类型/过滤器/已收计数/缓冲水位）/退订/暂停·恢复/清空缓冲；同一时刻允许多个并发订阅；订阅事件不中断既有工具调用流；订阅注册与撤销走门禁（FR-005，观察敏感面注册 risk 声明）与审计（FR-007）；**拉取语义** = AI 显式取回缓冲事件（全量取回或增量取回 lastId），不自动整段推入上下文 | 多订阅并发互不干扰（事件按订阅过滤投递）；订阅生命周期 API 单测全绿；拉取增量正确（无重复/无遗漏，lastId 语义）；无订阅时零常驻开销（NFR-007） | P0 |

## 7. 边界情况 (EC)

| ID | 场景 | 处理方式 |
|----|------|---------|
| EC-001 | 整页导航/reload 后旧订阅与缓冲随文档销毁（句柄失效） | 生命周期事件面明示「订阅已失效」（FR-010）；v3 reload 默认 ask 保持（deny 后不刷新，放行后需重新 read-state + 重新订阅，EC-009/014 语义沿）；旧 id 拉取/退订返回可读失效错误不中断会话 |
| EC-002 | 订阅缓冲溢出 / 事件洪峰（scroll/mousemove/高频轮询页面） | 最旧丢弃 + 丢弃计数标记（FR-013）；高频事件合并计数窗口（FR-014）；超每订阅/全通道预算 → 自动退订或暂停 + 提示（FR-014）；上下文只见摘要计数不撑爆（NFR-003） |
| EC-003 | 观察内容命中敏感面（cookie 值/URL 查询串含 token/键入内容/console·对话框文本/富剪贴板敏感文本） | 缺省脱敏掩码/占位/类型替代（FR-006）；明细读取需 trusted + ask；审计与日志无明文（grep 断言） |
| EC-004 | untrusted 上下文尝试配置拦截规则/cookie 写入/对话框自动应答策略/订阅敏感面 | 拒执行 + 「需 trusted 声明」可读错误（FR-005/030）；不静默降级、不截断执行；入审计 |
| EC-005 | 对话框 override 已安装但无匹配应答策略 | 缺省保守应答（confirm/prompt → dismiss 否定值、alert → 记录即返回）+ 事件 + 审计（FR-017）；页面不被阻塞；AI 可据事件补偿 |
| EC-006 | 对话框应答误确认风险（破坏性/覆盖/删除类文案被策略候选 accept） | 缺省 deny-accept：破坏性模式无显式 trusted pattern 匹配不得自动 accept（FR-017）；策略命中与应答入审计；帮助面公开护栏语义 |
| EC-007 | cookie 写面受限（HttpOnly 不可写/仅 HTTPS 可写 Secure/路径受限） | 分类转译可读（v3 FR-009 沿）；HttpOnly/跨域/域级管理入参 → 不支持 + 归属 chrome.cookies 契约预留（FR-019/020/025） |
| EC-008 | 剪贴板富内容读写授权失败（安全上下文非 HTTPS/缺权限/缺用户手势） | v3 FR-009 友好转译（授权路径指引），会话不中断；无手势系统剪贴板读 → 不支持说明（FR-022，NG-012） |
| EC-009 | 跨域/越界目标（跨域 cookie、网络观察非宿主自身 realm、跨域 iframe、closed shadow、worker 事件） | 不支持 + 归属说明（FR-025：F-14/CDP/content script 归属）；不静默、不跨 SOP 尝试；同源/页内面照常工作 |
| EC-010 | 浏览器原生对话框（HTTP 认证弹窗/权限 prompt/原生下载确认）出现 | 页面 JS override 不可 hook（NG-011）；事件面不可达 → 返回归属说明（FR-016/025：CDP/扩展侧）；不假装已捕获 |
| EC-011 | 无注入面/无环境支持（events/观察 ops 未注入、环境为 node、通道全局关） | 禁用态或可读错误（v2 dom「ops 未注入」语义沿 FR-002）；订阅注册返回「通道不可用」说明；不影响既有工具 |
| EC-012 | 事件投递后页面文档失效/句柄过期/越权拉取他人订阅 | 事件批次截止标记 + 重新 read-state 建议（EC-001 联动）；订阅 id 归属校验（越权访问返回可读错误 + 审计）；不静默返回空 |

### 9.5 拆分建议与波次（默认按单 Feature + P0/P1/P2 波次推进）
