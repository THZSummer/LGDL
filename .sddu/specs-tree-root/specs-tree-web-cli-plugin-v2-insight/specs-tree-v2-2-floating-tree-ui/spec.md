## 2. 上下文与边界

**为什么存在**：作者原话「**不允许放到设置面板里面**」「要操作简单」「**悬浮一个连接树，所有的连接能力都放到里面**」。V2-2 提供**侧栏常驻悬浮入口（FAB / 浮动按钮）+ 树抽屉**，四维度层级导航、检索/过滤、状态徽标。

**边界（做什么 / 不做什么）**

| ✅ 做什么 | ❌ 不做什么 |
|-----------|-------------|
| 侧栏内渲染常驻悬浮入口 + 树抽屉（复用 v1 三区 flex 全高布局与 `ui/settings/*` **实现**） | **不做页面注入悬浮层**（作者裁决②） |
| 四维度层级导航 + 状态徽标 + 检索/过滤 + 空态/降级可读。**[R2] 改为真层级树：按归属逐层展开/收起 + 键盘可达 + `aria-expanded` + 层级路径可读；命令节点逐层可操作（UI 载体）** | **不放进设置面板**（作者裁决③）；不取代设置面板 |
| 明暗适配；窄侧栏零水平溢出（复用 `overflow-wrap:anywhere` 等既有约定） | **不改 `options.html`**；不重命名 v1 既有元素 ID / `.entry-*` 选择器 |
| 不遮挡 composer / 消息区高度不回退 / 滚动跟随不回退 | 不做写操作（撤销/覆盖操作面归 V2-3；UI 只承载控件与回执） |

## 3. 目标与非目标

**Goals**：G1 侧栏常驻悬浮入口 + 树抽屉可用且可关；G2 四维度层级导航 + 状态徽标 + 空态可读；G3 **侧栏布局零回退（量化）**；G4 操作简单（入口到撤销 ≤2 次点击）；**[R2] G5 真层级树逐层展开/收起 + 键盘可达 + 层级路径可读 + 偏差文案清除**。
**Non-Goals**：NG1 页面注入悬浮层；NG2 放进设置面板 / 改 options；NG3 写操作（撤销/覆盖归 V2-3，UI 只承载控件）；NG4 新依赖/新权限；NG5 改动 v1 既有 DOM 契约。

| **FR-V2-072** **[R2]** | **展开状态语义 + 键盘可达**：根 + 一级默认展开、深层默认收起；展开/收起**会话内保持**；键盘（方向键/Enter）+ `aria-expanded` | 默认展开断言；会话保持断言；键盘可展开收起 + `aria-expanded` 正确（`test:ui`） |

| **FR-V2-077** **[R2·UI 侧]** | **`deny` 控件分层（UI）**：硬底线 `deny` → 无控件 + 不可覆盖原因可读；非硬底线 `deny` → 有 allow/ask 控件可改回 | 分层断言（零控件/有控件 + 原因文案） |
| **FR-V2-078** **[R2·UI 侧]** | **偏差文案替换 + `delay` 消歧保留**：「不提供命令级写入」「只读展示：命令级策略不可在树内修改」零命中；`delay` 消歧句（单源 `TREE_NO_ESCALATION_NOTE`）保留且与覆盖语义相容 | grep 偏差文案零命中；消歧句完整；无「第三档位」暗示 |

**量化阈值（`test:ui`，真实 dist，视口 400×900，断言只增不减）**

| 指标 | 阈值 |
|------|------|
| `#log` 计算 `flex-grow` | `= 1`（非 45vh 硬编码） |
| `#log` 稳态布局 | **≥ 589px 主（`clientHeight`）+ ≥ 65.0% 次（占比）**；测量条件 = **去镀铬稳态**（隐藏首run 引导条 + `#consent-slot` + `#send-reason`）；来源 **ADR-V2-006**。**以现状为准**（父 `spec.md` `AC-V2-002` 为权威）；本行历史口径「≥ 65.5%」已按父 spec 最小订正，历史叙述保留 |
| `#composer` 底边 − 视口底 | **∈ [0, +8px]**（贴底；**不得为负 = 不得被挤出视口**，D-079 回归） |
| 悬浮入口 boundingRect vs `#composer` boundingRect | **不相交**（无遮挡） |
| 文档级水平溢出（400px / 320px） | **= 0** |
| v1 既有 `#15a~#15q` 断言 | **零删减**（只增不减） |
