## 2. 上下文与边界

**为什么存在**：作者原话「**不允许放到设置面板里面**」「要操作简单」「**悬浮一个连接树，所有的连接能力都放到里面**」。V2-2 提供**侧栏常驻悬浮入口（FAB / 浮动按钮）+ 树抽屉**，四维度层级导航、检索/过滤、状态徽标。

**边界（做什么 / 不做什么）**

| ✅ 做什么 | ❌ 不做什么 |
|-----------|-------------|
| 侧栏内渲染常驻悬浮入口 + 树抽屉（复用 v1 三区 flex 全高布局与 `ui/settings/*` **实现**） | **不做页面注入悬浮层**（作者裁决②） |
| 四维度层级导航 + 状态徽标 + 检索/过滤 + 空态/降级可读 | **不放进设置面板**（作者裁决③）；不取代设置面板 |
| 明暗适配；窄侧栏零水平溢出（复用 `overflow-wrap:anywhere` 等既有约定） | **不改 `options.html`**；不重命名 v1 既有元素 ID / `.entry-*` 选择器 |
| 不遮挡 composer / 消息区高度不回退 / 滚动跟随不回退 | 不做写操作（操作面归 V2-3） |

## 3. 目标与非目标

**Goals**：G1 侧栏常驻悬浮入口 + 树抽屉可用且可关；G2 四维度层级导航 + 状态徽标 + 空态可读；G3 **侧栏布局零回退（量化）**；G4 操作简单（入口到撤销 ≤2 次点击）。
**Non-Goals**：NG1 页面注入悬浮层；NG2 放进设置面板 / 改 options；NG3 写操作；NG4 新依赖/新权限；NG5 改动 v1 既有 DOM 契约。

## 4. 功能需求

> 本子 Feature **直接承载父 spec 的以下 FR**（权威条文见父 `spec.md §5.3`）：

| 父 FR | 一句话 | 子级验收补充 |
|-------|--------|-------------|
| FR-V2-020 | 侧栏常驻悬浮入口（FAB/浮动按钮），可开合树抽屉 | `test:ui` 真实 dist：入口存在且可开合；位于侧栏 DOM |
| FR-V2-021 | 树抽屉：四维度导航 + 状态徽标 + 操作简单 | 四维度可见；入口到任一撤销操作层级 ≤2 |
| FR-V2-022 | 检索/过滤（只读，不改真值） | 过滤前后授权状态 diff 为空 |
| FR-V2-023 | 侧栏布局不回退（量化） | 见下「量化阈值」 |
| FR-V2-024 | 入口可发现 + 不干扰 + 既有契约零回归 | 入口与 composer 不相交；DOM id/类零重命名 |
| FR-V2-025 | 「不是提权面」文案钉死 | 文案含显式声明；`delay`/`deny` 节点无开关 |

**量化阈值（`test:ui`，真实 dist，视口 400×900，断言只增不减）**

| 指标 | 阈值 |
|------|------|
| `#log` 计算 `flex-grow` | `= 1`（非 45vh 硬编码） |
| `#log` 稳态高度占比 | **≥ 65.5%**（v1 基线 589px；不得回退） |
| `#composer` 底边 − 视口底 | **∈ [0, +8px]**（贴底；**不得为负 = 不得被挤出视口**，D-079 回归） |
| 悬浮入口 boundingRect vs `#composer` boundingRect | **不相交**（无遮挡） |
| 文档级水平溢出（400px / 320px） | **= 0** |
| v1 既有 `#15a~#15q` 断言 | **零删减**（只增不减） |
