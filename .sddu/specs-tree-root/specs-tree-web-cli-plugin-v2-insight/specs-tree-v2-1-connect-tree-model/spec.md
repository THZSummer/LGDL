## 2. 上下文与边界

**为什么存在**：把插件当前对用户完全不可见的四维度（站点授权面 / 浏览器能力面 / CLI 命令档案面 / LLM 连接面）聚合为**单一可投影的树模型**（确定性「当前状态 → 树节点」映射与快照），供 V2-2/V2-3/V2-4 全部 UI 消费。**纯读、零副作用、不渲染 UI。**

**边界（做什么 / 不做什么）**

| ✅ 做什么 | ❌ 不做什么 |
|-----------|-------------|
| 四维度 → 四层分组（森林）模型：以「本插件」为根的四个并列分组，允许跨层引用。**[R2] 组内改为真父子层级树 + 多归属主链 + 交叉引用徽标（父 FR-V2-070/071）** | 不改 `security/policy.ts` 判定链 / `PLUGIN_RISK_DEFAULTS` / `auto-authorize.ts` 4 条硬底线 |
| 站点（已授权/未授权/trust）、能力（静态 + 可选 + 6 开关 + tabs 开关）、命令（工具·子命令·risk·`allow`/`ask`/`delay(=deny)`·来源·`delayMs`·抑制态）、LLM（configured/provider/model，零明文 key）+ 会话分组 | 不新增权限、不做 `<all_urls>`、不加重 `content.js` |
| 确定性投影快照；命令集合对账（== `deriveTools()` + registry，**34 工具 / 142 子命令**）；**[R2] 默认档与覆盖生效档分列 + clamp 原因字段（父 FR-V2-013/079）** | 不碰 `packages/web-cli-base/**` |
| `state` 消息面 **additive** 扩展 | 不渲染 UI（UI 归 V2-2）；**不写任何覆盖**（覆盖写入归 V2-3；投影只读覆盖层） |
| 空态/降级可读；零明文（无 key / 无剪贴板·通知内容） | ~~不做命令级策略覆盖（明确排除）~~ **【R2 作废，以现状为准】** → **[R2 新约束] 不写覆盖、不绕过 clamp；不把硬底线 `deny` 表达为可关状态（非硬底线 `deny` 的可改回语义由 V2-3/V2-4 承载）** |

## 3. 目标与非目标

**Goals**：G1 四维度一眼可见的确定性投影模型；G2 命令/能力/站点集合与真值**不重不漏**；G3 零明文 + 零副作用 + additive 兼容；**[R2] G4 真父子层级 + 多归属主链 + 覆盖生效档/clamp 原因（纯读投影）**。
**Non-Goals**：NG1 不渲染 UI；NG2 **不写任何操作（含覆盖写入——归 V2-3）**；NG3 不改判定链/不放宽门禁；NG4 不新增权限/依赖/注入；~~NG5 不做命令级覆盖~~ **【R2 作废，以现状为准】** → **NG5R 不写覆盖、不绕过 clamp（覆盖写入归 V2-3；投影只读覆盖层）**。

## 4. 功能需求

> 本子 Feature **直接承载父 spec 的以下 FR**（权威条文见父 `spec.md §5.2`，逐条可测试；此处仅列范围）。**[R2]** 另承载父 `spec.md §5.7` 的 **FR-V2-070 / FR-V2-071 / FR-V2-079（模型侧）**：

| 父 FR | 一句话 | 子级验收补充 |
|-------|--------|-------------|
| FR-V2-010 | 四层分组（森林）模型（非严格树，如实说明）**〔R2·形式被 FR-V2-070 取代，以现状为准〕** | 模型含四分组根 + 跨层引用字段；**[R2] 组内为父子层级（非 `rows` 扁平）** |
| FR-V2-011 | 站点授权面投影（已授权/未授权/可取消授权 + trust） | 未授权站点**必须可见**；「可取消授权」态仅在 `authorized=true` |
| FR-V2-012 | 能力面投影（静态 `permissions` + `optional_permissions` + 6 开关 + tabs 开关） | 静态权限项**不得**显示为「可撤销」 |
| FR-V2-013 | 命令档案投影（档位 + risk + 来源 + `delayMs` + 抑制态） | 档位由 `PLUGIN_RISK_DEFAULTS` + S1/S2/S3 + 开关抑制态推导 |
| FR-V2-014 | LLM 连接面投影（零明文 key）+ 会话分组 | 输出 == `LlmStatusSummary`；grep 零命中 key |
| FR-V2-015 | 确定性 + 对账（不重不漏） | 双向集合等价 + 确定性快照 + 对齐 142 子命令基线 |
| FR-V2-016 | 纯读、零副作用、`state` 消息 additive 兼容 | 投影前后存储 diff 为空、无审计新增 |
| FR-V2-017 | 空态/降级可读 | ≥3 类空态可读文案；读失败可读降级 |
| **FR-V2-070** **[R2]** | **真树形归属层级（模型侧）**：四维度组内生成**父子层级**（非扁平 `rows`）；形状支持作者两例（站点→支持的命令→工具→子命令；命令→系统内置→工具→子命令） | 模型为层级结构（父/子字段，非 `rows` 平铺）；两例层级链可在模型层逐层枚举 |
| **FR-V2-071** **[R2]** | **多归属主链 + 交叉引用（模型侧）**：节点**唯一**、有主归属链；多址/多能力引用以**交叉引用字段**表达（不复制节点） | 节点 id 唯一（非复制）；主归属判定 + 交叉引用字段可单测；非主归属下钻到同一节点 |
| **FR-V2-079** **[R2]** | **覆盖面口径分列（模型侧）**：模型给出**实时投影面（28/94=122 卡）**与 **parity 基线（34/142）**分列计数；不夸大 | 模型计数 122 卡与基线 34/142 分列字段；「已全部渲染」类表述零命中 |

## 5. 非功能需求

| ID | 类别 | 需求 | 验收 |
|----|------|------|------|
| NFR-V21-001 | 零明文 | 投影不含 LLM key / 剪贴板内容 / 通知正文 / 页面数据 | grep 零命中；只记长度/路径等派生量 |
| NFR-V21-002 | 零副作用 | 投影为纯读（不改存储、不触发操作、不写审计） | 前后 diff 为空断言 |
| NFR-V21-003 | 确定性 | 同输入 → 同输出快照（可复现） | 两次投影一致断言 |
| NFR-V21-004 | 可测试性 | 投影纯函数化、node 可单测 | 单测覆盖四维度 + 对账 + 空态 |
| NFR-V21-005 | 体积 | 投影实现不新增 `content.js`；对 `sidepanel.js` 的增量纳入父级体积守卫（NFR-V2-001） | `content.js` ≤ 1,073,453 B |
| NFR-V21-006 **[R2]** | 可测试性·层级 | 层级模型 + 主归属/交叉引用 + clamp 原因均为**纯函数可单测**；确定性快照口径不变 | node 单测覆盖层级/归属/口径分列 |
| NFR-V21-007 **[R2]** | 只读边界 | 投影**只读**覆盖层（给出生效档），**不写**覆盖；投影前后存储 diff 为空 | 存储 diff 断言；覆盖写入不出现在 `src/insight/**` |
