## 1. 三项硬规则（先读）

1. **只允许收紧**：后续任何变更只允许把实测值压到**不高于**本文件已登记值；放宽必须由作者/编排器裁决，并显式登记「前后值 + 日期 + 理由 + 历史保留」。
2. **不得以放宽上限换功能**（NG-V3-010）：密度不达标时只能**改披露策略**（把元素真正收进 L1/L2），不得调高阈值、不得用 `display:none` / `visibility` / `opacity` 规避口径（口径只认 `hidden` 属性）。
3. **设计要求稿口径与真实产物口径分列**（A-UI-001）：两者**不得**合并成一个数字。

## 2. L0 密度口径（机器可复算，spec §9.1）

| # | 指标 | 定义 | 反作弊 |
|---|------|------|--------|
| C1 | 可点元素数 | 非 `hidden` 祖先 ∧ (标签 ∈ {BUTTON,A,INPUT,SELECT,TEXTAREA} ∨ `tabindex ≠ -1`) | **只有 `hidden` 豁免**；`display:none` / `visibility` / `opacity` / `pointer-events` / 移出视口 / `aria-hidden` 一律**不豁免** |
| C2 | 可见正文行 | `⌈Σ(自身直接文本去空白字符数) ÷ 34⌉` | `{{…}}` 占位符剔除；每元素只计一次；`34` = pin 常量 |
| C3 | 可见文本块数 | 自身直接文本非空且可见的元素个数 | 只登记，**不设上限** |
| C4 | 常驻分区数 | 测量根一级子元素中非 `hidden` 的个数 | 只登记，**不设上限**；**不是**「越小越好」 |

测量根 = `document.body`（父 ADR-V3-001：真实产物不新增 `#panel` 包裹层；设计稿口径的等价根是 `#panel`）。口径唯一实现源 = `test/ui/density-metrics.mjs`。

### 3.1 消息区下界（几何契约迁移）

`#log` clientHeight 下界 = **488 px**（400×900、默认档含待答决策卡的最坏情形实测 498 px − 10 px 已登记余量）。它取代 v2 insight 门的 589 px 锚点（ADR-V3-019 V31-S3），**只允许上调**；`test/ui/l0.mjs` 与 `test/ui/insight.mjs` 共用同一常量（`test/ui/density-metrics.mjs#LOG_CLIENT_HEIGHT_FLOOR`）。

### 3.2 C4 变化登记（只登记不上限）

| 项 | 值 |
|----|----|
| 本轮 C4（三档） | **6** / **6** / **6** |
| 上一轮（v1/v2 无此口径） | — |
| 变更日 | 2026-09-16 |
| 理由 | v3-1 新增 `#risk-rail`（独立成区、永不折叠）与 `#l0-statusbar`（一行状态栏） |
| 反直觉事实（必须保留） | ① L0 常驻分区数**高于**高密度参照稿 D（E=6 > D=5），原因是**风险位独立成区**（D3 铁律）——把分区数当密度指标会得出「E 比 D 更密」的错误结论；② 真实产物的 6 个分区 = `risk-rail` / `panel-top` / `panel-main` / `l0-statusbar` / `panel-bottom` / `<script>`（`<script>` 是 `display:none` 的 body 直接子元素，无布局占用但确属非 hidden 一级子元素）。 |
| 纪律 | **不得**以分区数下降作为密度达标证据，也**不得**以分区数上升为由放宽可点/行数上限（AC-V3-007）。 |

## 4. 设计稿口径（**分列**，仅作同源对账，不作验收依据）

| 口径 | 可点 | 行 | 文本块 | 分区 |

| **我们的口径实测** E（同一文件、同一 DOM） | **7** | **12** | **51** | **6** |
