# 迁移指引：从内置助手到 web-cli 插件（FR-036 / FR-039 / S-015 / FR-040）

> **文档定位**: 面向内置助手存量用户的迁移说明——**不自动迁移**，提供手动重配指引、使用习惯对照与已知差异清单；并给出过渡期双份维护控制与收敛计划。
> **适用范围**: v0.8（插件孵化）。**下线状态（2026-09-12 / TASK-016）**：Gate-D `D-1~D-7` 逐条评估达标（D-3 人工面 H6 为已文档化非阻塞项），内置助手已按 FR-038 代码下线（`packages/lgdl-web/src/ai/*` 移除 + `App.tsx` 摘除助手接线；单提交，可 `git revert`）。
> **保留对象（对象区分）**：页内 `web-cli-base` 机制层 + `web-cli-host` 协议暴露点保留（替代载体）。

## 1. 迁移原则（不自动迁移）

- 本插件**不读取、不写入、不迁移**内置助手在页面 `localStorage` 中的配置（含 `lgdl-ai-settings` 等键）。
- 首版**不提供一键迁移**，也不尝试猜测/复制旧配置；所有配置由用户在插件 options 页手动重配。
- 迁移**不阻断**：存量用户可使用仍保留旧版本内置助手的发布版；当前版本内置助手已下线，AI 能力由插件承载（见 `docs/release.md`）。
- 敏感数据（LLM key）不跨载体复制；插件 key 仅存于扩展本地存储，不回显明文。

### 1.1 不静默迁移提示（EC-016）

下线后页内 **不再有可用的 AI 面板**，但用户不会被静默丢进「无 AI 可用」状态——LGDL 工作台左栏 AI 区域静态展示迁移告知（标题「AI 能力已迁移至浏览器插件」），内容含：
1. AI 能力现由 **web-cli 浏览器插件**提供（含本站点 `web-cli-host` 协议暴露点说明）；
2. 插件构建与安装步骤（`npm run build --workspace @lgdl/web-cli-plugin` → `chrome://extensions` 加载 `packages/web-cli-plugin/dist`）；
3. 手动重配 LLM 厂商/Key（本插件不自动迁移）；
4. 授权当前站点后即可对话；
5. 迁移与回退指引（本文档）。

回退开关 `VITE_AI_ASSISTANT_FALLBACK=on` 时额外提示回退路径（默认 off，见 §5.4）。


## 2. 已知差异清单（内置助手 → 插件）

| 维度 | 内置助手（页内） | web-cli 插件 | 迁移影响 |
|------|------------------|--------------|----------|
| 载体 | LGDL 页面内的 AI 面板 | 浏览器扩展（MV3）side panel | 交互入口变化（页面按钮 → 扩展侧栏/图标） |
| LLM 配置 | 页面 `localStorage`（`lgdl-ai-settings`） | `chrome.storage.local`（插件独立） | **需手动重配**厂商 / Key / 模型 / Base URL |
| Key 隔离 | 页面上下文可读 | 仅 background 读取，页面不可读 | 安全性提升；需重新录入 Key |
| 授权模型 | 页面内隐式（同源） | per-origin 显式授权 + 二次确认 | 首次使用需授权目标站点 |
| 工具面 | 内置助手工具（页内直连） | 站点声明工具（`site:*`，经 RPC + 门禁） | 能力对照见 `docs/capability-matrix.md` |
| 站点范围 | 仅 LGDL 页内 | 任意声明 web-cli 协议的站点 | 能力扩展（通用消费端） |
| 审计 | 无统一审计面 | 全量审计（授权/确认/发现/执行），零明文 | 新增可查看/导出能力 |
| 风控护栏 | 无 | per-origin 频率限制 + 暂停/中止 | 默认启用；用户可暂停/中止 |
| 迁移 | — | 不自动迁移 | 见 §3 |

## 3. 手动重配指引（对照内置助手设置项）

1. **打开插件设置**：`chrome://extensions` → web-cli plugin → 「扩展程序选项」（或 options 页）。
2. **选择厂商**：与内置助手一致（deepseek / qwen / volc / volc-coding / volc-plan / tencent / openai / claude）。
3. **录入 API Key**：粘贴你在内置助手中使用的 Key（插件不回显明文，仅掩码展示）。
4. **设置模型 / Base URL**：如内置助手使用了自定义模型或端点，原样填入。
5. **保存并验证**：保存后发一条测试指令；若厂商端点不可直连，会得到可读提示（不会静默失败）。
6. **授权目标站点**：打开目标站点 → 点击扩展图标 → 在 side panel「授权当前站点」；首次授权含知情同意风险提示（见 `docs/compliance.md` §5）。
7. **确认旧配置**：内置助手旧配置仍留在页面 `localStorage`（本插件不改动）；必要时可自行清理，插件不代劳。

> 若厂商 Key 不可直连（CORS/网络），插件会给出可读降级提示「该厂商当前不可直连」，**不假装生效**。

## 4. 使用习惯对照

| 内置助手习惯 | 插件等价操作 |
|--------------|--------------|
| 页面内打开 AI 面板 | 点击扩展图标 → side panel 自动打开 |
| 直接输入指令 | 同（多轮对话；工具调用可视化） |
| 写操作即时生效 | 危险档位经**二次确认**后生效（允许/拒绝/超时=拒绝） |
| 页面刷新后继续 | 整页导航会**明示会话失效**，需重新授权/重连（不静默续接） |
| 查看历史 | side panel 对话记录 + 审计导出 |

### 5.4 回退预案

- **主预案 = 版本回退（唯一有效路径）**：下线为**单一提交**，可 `git revert` 恢复内置助手；前一版本保留 `src/ai/` 全量（**实测路径**：`git revert <TASK-016 下线提交>` → `ai/*` 与 `App.tsx` 接线一并恢复）。
- **可选临时入口**：构建期 flag `VITE_AI_ASSISTANT_FALLBACK`（**默认 off**）。落地位置：`packages/lgdl-web/src/fallback-flag.ts`（读 `import.meta.env.VITE_AI_ASSISTANT_FALLBACK`，仅 `'on'` 为启用）+ `src/vite-env.d.ts` 类型声明；消费点 = 工作台 AI 区域的迁移告知（on 时额外显示回退路径说明）。仅在紧急期启用；按 C-4 显式移除。
  - ⚠️ **语义边界**：因 C-3 同提交删除了 `ai/*`，**本 flag 不会在本构建中恢复旧面板**——恢复必须配合 `git revert`。flag 保留为显式旋钮与 C-4 终止里程碑锚点，避免「长期双份并存」误判。
- **不静默进入无 AI 可用状态**：Gate-D 未达标 → 不下线（保持内置助手）；已下线后 → 页内**静态迁移告知**明确「AI 能力现由插件提供 + 如何安装/授权」（§1.1 / EC-016）。
