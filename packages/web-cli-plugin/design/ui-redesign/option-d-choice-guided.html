P1 Alt 悬停拾取 按住 Alt（或常驻拾取）后悬停元素 描边高亮 + 浮动标签（语义路径 › 极短选择器 › 文本摘要） 零 与页面自身 Alt 快捷键 / 悬停菜单冲突；Windows 上 Alt 会聚焦浏览器菜单栏 只在拾取态拦截；松开 Alt 或 Esc 立即退出；不 preventDefault 页面其它默认行为；提供并列的「常驻拾取模式」保底
P2 Alt + 拖动 → 拖入侧栏 拾取态下在元素上按下并拖动 光标跟随「引用胶囊」；侧栏虚线落点高亮 +「松手即引用」；别处松手 =「已取消引用」 零 与页面拖放（拖拽排序 / 拖文件）冲突 仅在拾取态接管 mousedown；非拾取态完全不碰拖动
P3 右键引用（自绘菜单） 页面元素上 contextmenu 自绘菜单：引用到 web-cli / 用这里作为操作目标 / 复制选择器 / 引用选中文本 / 在此处拾取… / 交给原生菜单 零新增权限（路线 1） 劫持页面右键（路线 1 的真实代价） 仅已授权站点生效；菜单保留「交给页面原生菜单」出口；Esc / 点击空白即关；未授权站点零注入
P4 双向高亮联动 点侧栏引用 chip（正向）/ 元素被引用（反向） 页面元素描边闪动 + 滚动到可见；元素右上角角标 ①②③ 与 chip 序号一致 零 与页面自身角标 / 编号混淆 高对比实心圆 + 白描边；目标失效时 chip 降级为「目标已失效」并给原因
P5 执行可视化 引用题里选择「执行」类选项 页面元素描边闪动 +「正在操作此处…」徽标；侧栏回合显示进行中；完成打「已处理 ✓」角标 与该命令自身档位一致（dom.click 保底 ask / export ask） 与页面自身 loading 指示同时出现 只在已授权 + 已确认动作上显示；失败时角标转失败态 + 可读原因
P6 选中文本引用 页面里拖选文本后松手 选区旁浮出小气泡「引用选中内容（N 字）」→ 点击生成「文本引用」chip + 选择题 零（只读选区，不读剪贴板） 与页面自身划词工具条 / 词典插件重叠 气泡落在选区右下方 12px 且 1.8s 后自动淡出；也可用右键「引用选中文本」
G1 双击即引用 拾取态下双击元素，或 Shift + 双击 与 P2 / P3 同一条落地路径（chip + 选择题） 零 双击会选中页面文字 / 触发页面双击行为 只在拾取态接管；或要求 Shift 修饰键，页面双击默认行为不受影响
G2 悬停 ⊕ 引用徽标 悬停 600ms 且元素在站点声明的可引用白名单里 元素右上角出现 ⊕，点击即引用 零 密集页面噪声大 / 遮挡页面自身浮层 只对白名单元素生效 + 600ms 延迟 + 移开即消失 + 不拦截页面事件
G3 长按 500ms 拾取 可拾取元素上按住 500ms（不移动） 高亮 + 弹出「引用 / 作为操作目标」两项 零（未实现） 与页面长按菜单（触控 / 触控板）冲突 仅触屏 / 触控板启用；桌面保留 Alt 悬停
G4 滚动停止后的「当前视野主元素」候选 页面滚动停止 400ms 后 侧栏引用条浮出候选 chip「当前视野：接口清单」，可一键引用或忽略 零（未实现） 与页面滚动埋点 / 懒加载冲突 默认关闭、由站点声明开启；同一元素只提示一次
G5 Alt + 1~5 绑定第 N 个引用为操作对象 Alt + 数字键 当前题标题追加「作用于 ③ 端点行」，选项后果随之重算 零（未实现） 与浏览器 / 系统 Alt 组合键冲突 冲突时退化为 Ctrl+Alt+数字

权限现实：本插件 manifest 的静态权限为 activeTab / scripting / storage / sidePanel / tabs， 可选权限为 bookmarks / downloads / notifications / clipboardRead / clipboardWrite —— 没有 contextMenus， 因此 P3 走「content script 自绘菜单」路线（零新增权限），并把「交给页面原生菜单」写进菜单作为退让策略。
