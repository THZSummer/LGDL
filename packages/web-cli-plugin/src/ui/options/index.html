web-cli plugin 设置

如何使用

  1. 在本页配置 LLM 厂商与 API Key（BYOK，仅存扩展本地）。
  2. 打开目标站点标签页，点击浏览器工具栏的插件图标打开侧栏。
  3. 在侧栏「授权当前站点」，然后输入指令开始对话。

本页如何打开：侧栏顶部「配置模型 / 设置」按钮； 或 chrome://extensions → 本插件「详情」→「扩展程序选项」。

默认 1000：单次任务中 agent 工具调用的最大轮数（防死循环）。一般无需修改；调小可更早中断。

迁移指引（不自动迁移）

本插件独立配置 LLM，不读取也不写入内置助手的本地设置（浏览器页面存储）。 请按上方表单手动重配厂商、Key、模型（对照内置助手设置项）。首版不提供自动迁移。

合规与能力边界

站点自动化存在账号风控、条款冲突与数据外泄风险；使用前请确认目标站点条款允许自动化。 随插件仓库发布的文档：docs/compliance.md（合规评估与不适用清单）、 docs/protocol.md（站点中立协议说明）、docs/migration.md（不自动迁移与手动重配指引）。
